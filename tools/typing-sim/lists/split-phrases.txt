# Word split test phrases. One line per case:  context | strokes => expected
# The context is put in the field first (it may be empty), so the language model sees a real
# sentence. t:xyz taps each letter, s:xyz swipes the letters. A case is typed as one stroke list,
# with no space key between its parts. Lines starting with # are comments.
# The simulator's finger model misreads hello and there even as single swipes (help, the).
# Those are shape errors, so these cases avoid them.
# --- must split, trailing taps
So | s:today t:i => today I
Yes | s:this t:is => this is
I | s:want t:to => want to
I | s:think t:so => think so
So | s:what t:is => what is
I think | s:where t:is => where is
# --- must split, leading taps
 | t:i s:think => I think
We have | t:a s:lot => a lot
I want | t:to s:go => to go
It is | t:in s:the => in the
Today | t:we s:have => we have
This is | t:my s:friend => my friend
# --- must split, both ends (the user's cases)
 | t:i s:want t:a => I want a
 | t:a s:start t:is => a start is
 | t:is s:this t:a => is this a
 | t:i s:have t:a => I have a
# --- must split, a tap run holding two words
Well | s:this t:is t:a => this is a
 | s:what t:is t:a => what is a
 | t:it t:is s:time => it is time
# --- partial tap run: the first taps finish the swiped word
 | s:thi t:s t:is => this is
I will | s:wor t:k t:on => work on
# --- must join, tapped ending
I like | s:cat t:s => cats
He | s:work t:ed => worked
She | s:play t:s => plays

She | s:go t:es => goes
He | s:want t:s => wants
# --- must join, tapped start
Tell me | t:a s:bout => about
Try it | t:a s:gain => again

Go | t:a s:way => away
He went | t:in s:to => into

In this | s:are t:a => area
